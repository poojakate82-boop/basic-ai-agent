# ADR 1: Selection of Tech Stack for Basic AI Agent

## Status
Accepted

## Context
This project is developed for the AI-Augmented Workflow course. The objective is to build a basic AI Agent using Python and an LLM.

## Decision
The project will use:
- Python
- OpenAI API or Ollama
- Git and GitHub
- Visual Studio Code

## Consequences

### Advantages
- Beginner friendly
- Easy to maintain
- Supports AI-assisted coding

### Disadvantages
- OpenAI API requires an API key.
- AI-generated code should be reviewed before use.
